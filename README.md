## What it does

`main.py` (Python 3, pure standard library — no network, no secrets) writes
one sentence to `/output/entry.txt`: the best advice the writer ever
received, from his father after a twelve-hour shift. The program validates
the sentence first (1–200 characters, exactly one sentence, no
leading/trailing/double space), writes it with no trailing newline, then
re-reads the bytes and fails loudly if they differ. Set `ENTRY_OUTPUT` to
override the output path for local testing.

## Run

```sh
python3 main.py
```
